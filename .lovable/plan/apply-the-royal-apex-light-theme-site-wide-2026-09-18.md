# Apply the Royal Apex light theme site-wide

## Scope
- Make the light editorial palette, typography, borders, shadows, and motion the default across public pages, sign-in/status screens, and all role dashboards.
- Preserve every existing workflow, permission rule, form, table, and navigation destination.

## Implementation
- Promote the homepage’s Royal Apex tokens to the global design system using light background, white surfaces, royal navy actions, golden amber highlights, and emerald success states.
- Standardize Libre Baskerville headings and IBM Plex Sans body text across all screens.
- Replace legacy dark-only page and control styling with semantic theme classes so cards, tables, forms, dialogs, navigation, and dashboard tools remain readable.
- Keep restrained rise-in and interaction transitions, with reduced-motion support.
- Add route-specific page metadata where missing.

## Verification
- Check public pages, authentication, and representative National, State, District, and Match Official screens at desktop and mobile sizes.
- Confirm no clipped text, dark remnants, console failures, or broken interactions.
- Confirm the latest preview build is healthy.
